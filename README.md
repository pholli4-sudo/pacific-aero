# pacific-aero.com

Demo site for Pacific Aero Partners, hosted on GitHub Pages with HTTPS enforced. Not indexed: `robots.txt` disallows all crawlers and `index.html` carries a noindex meta tag.

- `index.html` — the one-page site (mono Gate mark, Deep Pacific navy)
- `assets/logo-gate.svg`, `assets/favicon.svg` — the chosen mark
- `brand/` — identity proposal assets (all four directions), kept locally

Edit `index.html` and push to `main` to update the site.
